# CONTEXT — proiect_web1 vocabulary

<!-- graffino-agentic:begin v1 -->
> The approved terms for this project. Use each term exactly as defined, in the part
> of speech given. Never swap in a synonym; never use a word on an _Avoid_ line.
<!-- graffino-agentic:end -->

**Application** (noun) — The web project codebase and running system.
_Avoid_: applet, program, software suite.

**Feature** (noun) — A distinct, user-facing piece of functionality specified in the project requirements.
_Avoid_: capability, module, perk.

**Component** (noun) — A reusable UI building block (e.g., button, card, navigation bar).
_Avoid_: widget, element, control.

**Screen** (noun) — A complete view or page displayed to the user.
_Avoid_: window, tab, canvas.

**Ledger** (noun) — The version-controlled knowledge files in `docs/agents/` (decisions, patterns, contracts, open questions).
_Avoid_: database, knowledgebase, wiki.
